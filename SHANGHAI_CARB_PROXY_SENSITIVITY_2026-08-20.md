# ShanghaiT2DM meal carbohydrate proxy sensitivity — 2026-08-20

## Scope

Exploratory analysis using the 20 directly parseable `.xlsx` ShanghaiT2DM sessions. Dietary intake rows contain food names plus food weights, not carbohydrate grams. A coarse food-to-carbohydrate density map was therefore used only as a **relative meal-load proxy**, not as nutritional ground truth.

## Parsed meal records

Usable meal records with a parsable food-weight entry:

- Breakfast: n=154
- Lunch: n=156
- Dinner: n=161

Observed meal-time means (minutes after midnight):

- Breakfast: 435.5 min (~07:15), SD 45.6 min
- Lunch: 707.8 min (~11:48), SD 52.8 min
- Dinner: 1057.2 min (~17:37), SD 65.0 min

Crude carbohydrate proxy distribution:

| Meal | Mean proxy g | SD | Median | Approx CV |
|---|---:|---:|---:|---:|
| Breakfast | 41.9 | 22.4 | 39.2 | 0.54 |
| Lunch | 30.2 | 19.1 | 30.6 | 0.63 |
| Dinner | 25.5 | 17.6 | 24.8 | 0.69 |

Absolute values should **not** be interpreted as measured carbohydrate intake because mixed dishes and ambiguous labels are present. The useful signal is the large relative heterogeneity.

## Sensitivity test 1: use absolute proxy values directly

Feeding the crude proxy values directly into the current kernel model while keeping insulin doses fixed caused severe over-insulinization:

- Mean glucose ~112 mg/dL
- TBR ~23%

This falsifies direct use of the crude absolute proxy. The model's default 50/70/60 g meal scale and the proxy's absolute nutrient scale are not interchangeable.

## Sensitivity test 2: preserve model meal means, use only proxy dispersion

The proxy deviations were re-centered around the model's nominal meal means (50/70/60 g). Applying the full observed proxy dispersion produced excessive variability:

- Mean ~150 mg/dL
- SD ~70 mg/dL
- TBR ~9.5%

Thus the raw proxy CV cannot be inserted one-to-one either.

## Sensitivity test 3: attenuated meal-load heterogeneity

Using empirical meal-time variation plus an attenuated fraction of the proxy load variation showed a strong time-of-day effect. Breakfast-load heterogeneity selectively increases pre-lunch variance and largely decays before pre-dinner; lunch-load heterogeneity primarily increases pre-dinner variance.

A representative setting (exploratory, not frozen):

- Breakfast mean effective load ~44–45 g instead of 50 g
- Breakfast proxy deviation retained at ~70–80%
- Lunch proxy deviation retained at ~20%

This produced approximately:

- Pre-lunch ~141–143 mg/dL, SD ~50–53 mg/dL
- Pre-dinner ~149 mg/dL, SD ~50 mg/dL

These are close to the directly observed meal-relative Shanghai subset targets:

- Pre-lunch ~141 mg/dL, SD ~51 mg/dL
- Pre-dinner ~150 mg/dL, SD ~51 mg/dL

However, when insulin dosing was held fixed, whole-day TBR rose to ~4–5%, above the full-cohort Shanghai target (~2.36%). Therefore meal-load heterogeneity alone is not sufficient; **meal load and treatment response cannot be varied independently**.

## Meal proxy versus nearby insulin dose

A preliminary nearest-meal insulin matching in the same `.xlsx` subset found weak/no simple positive correlation between crude meal-load proxy and nearby insulin dose:

- Breakfast: n=76, Pearson ~+0.10, Spearman ~−0.09
- Lunch: n=36, Pearson ~−0.19, Spearman ~−0.31
- Dinner: n=69, Pearson ~+0.13, Spearman ~+0.29

These estimates are noisy because the cohort contains premixed insulin, CSII, non-insulin therapy, repeated/structured pump entries, and meal-dose timing ambiguity. They should not be treated as a physiological insulin-to-carbohydrate ratio estimate.

## Interpretation

1. The previously missing pre-lunch/pre-dinner SD can plausibly be generated by **meal-specific effective carbohydrate/load heterogeneity** without widening static patient phenotype distributions.
2. The particularly useful component is breakfast-load variation, because its effect is strong at pre-lunch and mostly attenuated by pre-dinner.
3. Varying meal load while leaving insulin fully fixed overproduces hypoglycemia. A realistic model needs a partial coupling between meal load and prandial treatment, plus residual mismatch.
4. Therefore the next mechanistic layer should not be generic glucose noise. It should be a **meal-treatment mismatch variable** with partial compensation, e.g. effective meal load + partially adjusted prandial dose.
5. Do not freeze the exploratory carb proxy values themselves; freeze only the qualitative result that meal-specific load heterogeneity is required and should be partially coupled to treatment.
