# T1DM distributional validation — Run 23 handoff (2026-08-23)

Production remains frozen. No `engine.js` or `patient_generator.js` change was made or approved. GitHub Actions was not used.

## Starting point
Run 22 showed that the frozen simulator's negative raw daytime r120 is overwhelmingly generated by its deterministic repeated 24-hour meal/bolus waveform. After subtracting each patient's mean glucose at each clock-time bin, simulated residual SD was only ~0.133 mg/dL and residual r30/r60/r120/r240 were approximately 1.0. The decisive missing comparison was the same estimand in external AZT1D CGM.

## What Run 23 did
The public Glucose-ML AZT1D source and schema were re-verified. Each participant CSV has `timestamp,glucose_value_mg_dl`; the directory is a harmonized derivative of the original AZT1D dataset (Mendeley DOI 10.17632/gk9m674wcx.1, CC BY 4.0).

The existing JS audit was then hardened with an independent Python implementation:
- `validation/scripts/azt1d_clock_demeaned_acf_audit_v2.py`

It computes patient-level raw and residual ACF at 30/60/120/240 min from exact timestamp pairs and reports patient medians/IQRs. In addition to ordinary clock-time de-meaning, it implements **leave-one-day-out (LOO) clock de-meaning** so each day's expected daily trajectory is estimated from other days only. This directly tests whether self-inclusion is artificially shrinking residual variance in short simulated runs.

Additional diagnostics:
- exact pair counts at every lag;
- residual and LOO residual SD;
- recording days per patient;
- configurable 5/10/15/30-min clock bins;
- CSV-directory input for canonical Glucose-ML audit;
- optional parquet input for secondary GlucoFM-Bench sensitivity analysis.

The script performs no interpolation.

## Local verification
`python -m py_compile` passed.

A synthetic 3-subject × 12-day CGM smoke test with a repeated daily waveform plus AR(1) residual was executed locally. Raw ACF was substantially higher/longer than clock-demeaned ACF, while ordinary and LOO de-meaning agreed closely in this balanced synthetic case. This verifies the intended separation of repeated trajectory from residual covariance and the LOO path. Synthetic values are not biological evidence.

## Important source decision
GlucoFM-Bench was inspected as a possible execution route. It contains AZT1D participant time series, but its published preprocessing linearly interpolates gaps shorter than one hour. Therefore it should **not replace the Glucose-ML exact-pair analysis as the canonical estimand**; it may be used only as a sensitivity analysis.

## What remains blocked in this run
The canonical AZT1D clock-demeaned numerical result was not fabricated. Although connected GitHub can inspect the public 25 participant CSVs, the local execution container could not resolve external hosts/download the multi-file dataset, and the Hugging Face binary download path was unavailable. File Library search also found no AZT1D archive.

Thus the bottleneck is now execution/data transfer, not analysis design.

## Current interpretation
Do not add new physiology or tune raw r120.

Raw daytime ACF should remain classified as a mixed estimand:
1. repeated mean 24-hour trajectory geometry;
2. covariance of deviations around that trajectory.

The external residual target must be measured before deciding whether daytime needs a richer dynamic state-space model. LOO de-meaning should be reported alongside ordinary de-meaning to rule out self-inclusion bias.
