# Daytime component decomposition — 2026-08-23

## Question

The frozen model has a strongly negative daytime r120 (about -0.52 in the current local protocol) while AZT1D daytime r120 is +0.102. Prior broad parameter screens showed that weaker restoreK only helps modestly and that large rapid-profile changes or meal mismatch worsen tails before solving the problem.

This analysis directly asks: **which term in the frozen glucose equation is responsible for the 60–180 min post-meal reversal?**

## Method

- validation-only in-memory instrumentation; production `engine.js` is unchanged
- local Node execution only; no GitHub Actions
- frozen engine 0.94-browser-port and generator 0.79-browser-port
- N=60 generated T1DM patients
- 7 days per patient
- 3 meal events/day
- 1,260 meal events total
- seeds 980001–980060
- per-minute glucose increment was decomposed into:
  - meal carbohydrate input
  - rapid bolus insulin effect
  - basal-delta term
  - restore-to-setpoint term
  - counterregulation
  - hepatic drive

For each meal, each component was integrated over 0–60, 60–120, and 120–180 min after meal time. Event-wise medians are reported.

## Result

Median glucose change relative to meal time:
- +60 min: **+102.6 mg/dL**
- +120 min: **+53.2 mg/dL**
- +180 min: **+4.2 mg/dL**

So the typical trajectory rises strongly for the first hour, then loses roughly 50 mg/dL in each of the next two hours.

The 60–120 min reversal is therefore dominated by the rapid-bolus term: meal input still contributes +57.7 mg/dL, but rapid insulin contributes -98.6 mg/dL. Restore contributes only about -9.0 mg/dL.

The same pattern persists from 120–180 min: meal +26.7 versus rapid -74.8, while restore is nearly neutral (-0.8).

Using the event-median per-minute components, `meal + rapid + restore` first becomes negative at approximately **+59 min after the meal**.

## Interpretation

This materially narrows the mechanism diagnosis.

The wrong-sign daytime r120 is **not primarily generated by restoreK**. Restore contributes to the early decline, but the dominant mechanism is the deterministic crossing of the meal and rapid-insulin kernels: carbohydrate input decays quickly while the rapid-bolus effect remains stronger from roughly 1 h onward.

This also explains why:
- weakening restoreK previously produced only modest ACF improvement;
- meal/bolus mismatch noise improved ACF by breaking phase locking but did not remove the underlying deterministic waveform;
- large rapid-profile broadening could move marginals but often worsened tails without fixing the sign.

The current engine therefore appears to encode a meal/rapid **relative-shape mismatch**, not merely insufficient stochasticity.

## Decision

No production change yet.

However, future daytime revision work should now focus on the **relative meal-versus-rapid response geometry**, especially the 45–180 min interval, rather than tuning restore persistence or adding more generic noise.

The next high-information experiment should perturb the two kernels in a constrained way while preserving clinically plausible insulin action and total exposure, and measure:
1. the meal/rapid crossing time;
2. daytime r60/r120/r240;
3. mean/CV/TBR/TAR;
4. 4-point distributions.

Because prior simple meal-kernel widening worsened results, the useful question is not “make meals slower” in isolation. The next screen should test **relative timing/shape pairs** (e.g. modestly less front-loaded rapid action and/or altered meal fast-fraction) and reject any pair that improves r120 mainly by increasing hypoglycemia or destabilizing marginals.

Overnight remains a separate structural problem: this decomposition does not address the near-deterministic overnight ACF≈1.
