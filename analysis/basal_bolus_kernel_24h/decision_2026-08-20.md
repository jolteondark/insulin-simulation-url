# Basal-bolus kernel 24h decision (2026-08-20)

Target: ShanghaiT2DM clinically classified basal-bolus group (7 sessions): pooled mean 164.3 mg/dL, SD 57.6, TBR 1.51%, TIR 61.62%, TAR 36.88%; premeal B/L/D 147.7±35.4 / 156.7±67.6 / 171.9±65.0; patient-mean breakfast Δ120 44.4 with between-patient SD 28.1.

Candidate environment fixed during this screen: equilibrium center 147 mg/dL, equilibrium SD 35 mg/dL, prandial coverage 0.80, meal variability scale 0.55 of crude Shanghai staple proxy CV, bolus mismatch SD 0.10.

A 20-point global kernel grid was screened: meal tau 50/55/60/65/70 min × bolus tau 120/135/150/165 min.

Best aggregate score in the local exact-formula reconstruction was meal tau 70 / bolus tau 135 min:
- pooled 167.3±55.6 mg/dL
- TBR 1.53%, TIR 62.94%, TAR 35.52%
- pre-breakfast 149.7±34.7
- pre-lunch 168.9±51.6
- pre-dinner 155.0±65.5
- patient-mean Δ120 39.0; between-patient SD 19.0

No global kernel candidate reproduced the full 24-hour phase structure. Moving meal/bolus kinetics enough to repair breakfast Δ120 systematically pushed pre-lunch too high and pre-dinner too low. Therefore a single globally modified meal/bolus kernel is rejected as the next model change.

Critical treatment-context observation: the 7-session Shanghai basal-bolus audit is dominated by regular insulin: 2025 Novolin R + glargine; 2035/2036/2043/2074 Novolin R + basal; 2094 Humulin R + glargine; only 2090 uses rapid glulisine. Thus 6/7 sessions use regular insulin. Comparing this group to a simulator with one generic bolus kernel confounds physiology with insulin formulation kinetics.

Decision:
1. Do not replace the global bolus kernel with tau 135–150 min.
2. Add / validate insulin-formulation-specific action kernels before introducing a new generic meal-response latent parameter.
3. Re-stratify Shanghai basal-bolus into regular-insulin vs rapid-analog exposure where possible; use the regular-insulin-dominant fingerprint to calibrate regular insulin kinetics, not a universal bolus kernel.
4. Reassess residual between-patient Δ120 heterogeneity only after formulation kinetics are matched.

Main remains untouched; this is validation-only experimental work.
